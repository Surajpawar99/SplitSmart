## ✨ Key Features

- 💸 **Effortless Expense Splitting**: Split bills equally or customize amounts per member with exact rupee-paise accuracy.
- ⚡ **Smart Debt Simplification**: Proprietary mathematical settlement algorithm reduces redundant transactions to the minimum possible transfers.
- 📸 **Receipt & Bill Attachments**: Attach photos of bills and receipts with pinch-to-zoom verification.
- 🔗 **QR Code Group Invitations**: Invite friends and flatmates to your group in seconds using secure QR codes.
- 📊 **Real-Time Balances & Graphs**: Clear overview of who owes who with visual net positions.
- 🛡️ **Offline-First Resilience**: Full offline functionality with seamless cloud synchronization.
- 🎨 **Modern Fintech UI**: Clean Material 3 design crafted with dark and light theme support.
